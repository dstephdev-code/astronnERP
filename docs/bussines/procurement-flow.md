1. Инженер делает запрос на детали
2. Менеджер по закупкам по запросу формирует лист закупок
3. Этот лист согласуется с бухгалтерией
4. Отправляется контрагенту на заключение договора
5. Вносится аванс
6. По договору приходят детали
7. По факту их прихода формируется приходная накладная инженером по качеству
8. По факту закрытия всех пунктов договора бухгалтерия оформляет проводку и оплачивает остаток после аванса
