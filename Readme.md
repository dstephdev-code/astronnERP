## Astronn ERP System

ERP System project for E2E procurement service.
Designed for using on local market and import purchases.

It will be useful to digitalize a whole process and have consistent storage of all the actions and documents.

Wrote using .NET 10 platform as a base and PostgreSQL database as storage vault.

Used DDD for whole solution, VSA for WebApi project. CQRS principe in maintaining access to DB.
